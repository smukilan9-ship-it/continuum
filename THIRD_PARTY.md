# Third-party software and content

Continuum is original application code built with these open-source foundations:

- Next.js, React, TypeScript, Tailwind CSS — MIT
- Radix UI, Lucide, React Flow, KaTeX — MIT
- Zod, Drizzle ORM, Model Context Protocol SDK — MIT
- Supabase client libraries — MIT

The physics seed is freshly authored from standard CBSE Class 12 concepts. It does not reproduce proprietary textbook passages. Research passages in the demo are synthetic, clearly labelled sample excerpts created for this prototype.
